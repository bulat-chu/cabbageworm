## FramePad X201 Tablet (ThinkPad X201 Tablet + Framework 13) ##

Есть то за, чем можно наблюдать вечно: как течёт вода, как горит огонь, как меняются времена года. 

А есть старые ноутбуки ThinkPad, что могут функционировать относительно своих сородичей вечно. К сожалению, долговечность не гарантирует актуальность.

Именно с этой мыслю я начал свой проект по модернизации старого X201 Tablet.
